About this directory

SKM Directory is a JustDial-style local business directory built entirely on open data — real places from OpenStreetMap, no scraped or fake listings. Search by city and category to see shops, services and amenities with their location on a map.

Frequently asked questions

Is the data real?

Yes — every result comes from OpenStreetMap, the open map database, so it reflects real mapped places rather than generated content.

How is this different from JustDial?

JustDial relies on a proprietary, partly paid listings database. This directory uses open map data, so it is free, transparent and community-maintained.

Can I use it offline or self-host it?

Yes — the stack is free and keyless (OpenStreetMap tiles + Overpass API), so it can run on any static host.

Does it show contact details?

Where OpenStreetMap has a phone or website for a place, it is shown on the card.
